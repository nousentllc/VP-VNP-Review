# Pass 13A · Why the balanced decomposition permits gate reuse

**November 25, 2026. Disposition.** We reconstructed E.4 for any gate list admitted by the paper, including identical inputs to a binary gate and any number of later uses. The proof records one complementary coefficient table per **original gate** and **balanced subset**. The number of paths through that gate can enter its table values. It never enters the dimension of the index connecting the two sides of a fixed cut. This answers the outstanding gate-reuse question in pass 12. Converting this representation into a lower bound requires separate spectral and geometric estimates. ## 1. The exact input and the coefficient being tracked

Fix a commutative semiring $R$, an integer $k\ge2$, and a common finite label set $T$. Block $a$ contains the variables $X_{a,t}$, $t\in T$. A size-$L$ circuit is a list $p_0,\ldots,p_{L-1}$ of polynomials. Each entry is an input variable, a constant, or the sum or product of two earlier entries. The indices may coincide. A designated entry $p_\gamma$ is the output and need not be last. There is no restriction on signs in rings, on individual gate degrees, or on how many times a gate is read. E.4 starts with any such circuit for any polynomial $P$ and extracts its multidegree $(1,\ldots,1)$ component. The manuscript assumes a commutative ring, while the formal proof of this decomposition also covers commutative semirings. [Model](../primary/vp-vnp/Nc/LowDegree.lean#L24) · [Formal E.4](../primary/vp-vnp/Paper/Flat.lean#L229)

For $S\subseteq[k]$ and a choice $x\in T^k$, define
$$
m_S(x)=\prod_{a\in S}X_{a,x_a},\qquad c_{i,S}(x)=[m_S(x)]p_i.
$$
The bracket extracts the coefficient of the exact monomial, with degree zero in all unselected blocks. Thus $c_{i,S}$ depends only on $x|_S$, and $c_{i,\varnothing}$ is the constant coefficient. At a sum gate these tables add. At a product gate $p_i=p_u p_v$,
$$
c_{i,S}(x)=\sum_{B\subseteq S} c_{u,B}(x)c_{v,S\setminus B}(x).
$$
Every selected variable has exponent one. In any ordered pair of monomials multiplying to $m_S(x)$ it comes from exactly one input, and all other variables have exponent zero in both inputs. This gives a bijection with *ordered* allocations to the two input sockets. The calculation applies even if $u=v$ or either polynomial contains terms of much higher degree. No evaluations or interpolation over the field are required. [Coefficient definition](../primary/vp-vnp/Nc/CaseI/Multi.lean#L54) · [Product bijection](../primary/vp-vnp/Nc/CaseI/Multi.lean#L65)

## 2. The invariant, including the cofactor's allowed variables

Use the same reference integer $k$ throughout recursion. A subset $A$ is balanced if $k\le3|A|\le2k$; call $S$ large if $3|S|>2k$. For every gate $i$ and large $S$, the induction constructs complementary tables $H^{i,S}_{\delta,A}$ satisfying
$$
c_{i,S}(x)=\sum_{\substack{A\subseteq S\\k\le3|A|\le2k}}\ \sum_{\delta=0}^{L-1} c_{\delta,A}(x)\,H^{i,S}_{\delta,A}(x|_{S\setminus A}).
$$
The superscript changes as the proof moves between gates and subsets. The first factor for a fixed $(\delta,A)$ is always the same coefficient table of the same original gate. The second factor is unrestricted in magnitude and may contain the sum of many downstream contributions. Crucially it cannot vary with an input coordinate in $A$. [Definition of the invariant](../primary/vp-vnp/Nc/CaseI/Multi.lean#L134) · [Cofactor locality under multiplication](../primary/vp-vnp/Nc/CaseI/Multi.lean#L198)

**Leaves and addition.** A large $S$ contains at least two blocks. A variable or scalar has zero coefficient there. At $p_i=p_u+p_v$, add the two complementary tables entrywise. This uses $ch+ch'=c(h+h')$, with no need to compare or distinguish the paths arriving at $u$ and $v$. Reading the same input twice supplies $h+h$. The surviving table can vanish in positive characteristic. [Leaves](../primary/vp-vnp/Nc/CaseI/Multi.lean#L228) · [Entrywise addition](../primary/vp-vnp/Nc/CaseI/Multi.lean#L156)

**Product.** For each ordered split $B\sqcup C=S$, the source uses the following deterministic choice. If $3|B|\ge k$, take the left component and its gate $u$. Otherwise take the right component and gate $v$. In the latter case $3|C|=3|S|-3|B|>k$. Call the chosen component $D$, its gate $r$, and its sibling gate $s$. If $3|D|\le2k$, stop at $(r,D)$ and insert the sibling coefficient as its cofactor. If $3|D|>2k$, apply the invariant at the earlier gate $r$ on $D$. For $A\subseteq D$, multiply the resulting cofactor by $c_{s,S\setminus D}$; the two factors see only $(D\setminus A)\sqcup(S\setminus D)=S\setminus A$. Summing over all splits adds contributions to the same table entry. Commutativity allows either child to be written first. Strong induction is on gate index: it still descends if $D=S$ and the sibling supplies a constant coefficient. A recursion whose only decreasing measure was $|S|$ would miss this case. [Single entry](../primary/vp-vnp/Nc/CaseI/Multi.lean#L176) · [Product choices and induction](../primary/vp-vnp/Nc/CaseI/Multi.lean#L250)

**Output.** Take $i=\gamma$ and $S=[k]$, which is large. Package the two tables on $A$ and $A^c$ as multihomogeneous polynomials, e.g. $g_{A,\delta}=\sum_{y\in T^A}c_{\delta,A}(y)m_A(y)$ and analogously $h_{A,\delta}$ from $H$. Complementary supports mean that each pair of local assignments combines into a unique full assignment, so the product has exactly the desired coefficient table. Equality of all these coefficients gives the multidegree-$(1,\ldots,1)$ part of $P$. For each fixed $A$ there are at most $L$ products: one slot for each original index $\delta$, including zero slots. This does not bound the size of a circuit computing an individual cofactor. If $T$ is empty, the full block component is zero and the source treats this separately. [Disjoint-block product](../primary/vp-vnp/Paper/Flat.lean#L209) · [Packaging and empty-label case](../primary/vp-vnp/Paper/Flat.lean#L233) · [Coefficient interface](../primary/vp-vnp/Paper/Flat.lean#L263)

## 3. Two explicit tests of the accounting

**Two uses with different contexts.** For $k=4$ the balanced sets are precisely the pairs of blocks. Form $g=A_0B_0$ once and compute $g(C_0D_0)+g(C_1D_1)$ through two product gates and a sum. The complementary table for the original $g$ and $A=\{A,B\}$ is $[c=d=0]+[c=d=1]$. It takes value one at both $00$ and $11$ and zero at $01,10$. One gate label serves both contexts; retaining only the first use gives the wrong coefficient at $A_0B_0C_1D_1$. These factors give a single rank-one term across this cut, although the complementary table itself can distinguish several assignments.

**A gate paired with itself.** Form $u=A_0B_0+C_0D_0$ and feed $u$ to both sockets of a multiplication gate. Then
$$
u^2=(A_0B_0)^2+2A_0B_0C_0D_0+(C_0D_0)^2.
$$
The endpoint coefficient is $2$ in the integers and $0$ modulo two. Routing $AB$ to the first socket and $CD$ to the second contributes one; routing $CD$ first and $AB$ second contributes another. The source's left-first convention sends these to $(u,AB)$ and $(u,CD)$ respectively. Replacing ordered allocations by unordered partitions returns one in both coefficient rings, including the case where the target coefficient vanishes. This is a counterexample to that simplification. ## 4. Why the index bound is the one E.7 needs

For the complete-network polynomial, the label at node $a$ is its table of incident half-edge strings. The table depends only on inputs at those ends. For each balanced $A$, put the $g$ tables at one hub and the $h$ tables at a second hub. One dimension-$L$ equality wire lets both hubs read the same $\delta$. Contracting it sums the products $g_{A,\delta}h_{A,\delta}$ across that cut. The placement transfers to shared physical positions via A.3. A separate sum over $J$ balanced sets reconstructs the full tensor, with $1\le J\le2^k$ for $k\ge2$. E.7 charges the selector via $J^{g_\varphi(P_{\rm ends})}$ and takes the maximum spectral value of these hub networks. The dimension $L$ occurs inside each hub network, while $J$ counts possible cuts. Conflating these indices would change the lower-bound calculation. Only a single cut's summand has the stated rank bound across that cut. For the entire sum, E.7 and the subsequent geometry do additional work. From the review root run `python3 checks/pass13a_gate_reuse.py`. It constructs 12 explicit circuits over the integers, including deep chains of identical-parent additions, signed gates and reflected product chains. For binary labels and two through six blocks, it checks 441,920 coefficients against direct expansion retaining all monomials. It verifies 58,384 gate/subset/assignment decompositions and checks complementary-table locality for every entry, including zeros. The square also tests reduction modulo two. These exact examples cannot by themselves establish the universal quantifier. The gate induction above addresses it.
