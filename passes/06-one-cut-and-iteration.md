## J.4 · Why the sum survives repeated cuts

Fix an accepting parent run of weight w with output list y₁,…,yₘ. Substitute each child's finite cut expansion into w times the product of their values. Distributivity gives a sum over one accepting child choice for **each occurrence** in the list. The composite run carries w times the product of their weights and returns the concatenated list of grandchildren. With no children this contributes w. If a required child has no accepting choice, this parent contributes zero. Identical children may choose different runs. This argument needs neither positive weights nor division. The formal list fold proves this identity and propagates plainness through the chosen lists. ## J.4 · Rounding, stopping and total cost

Let U = v^H and use Λ for the overhead in the iteration. The formal wrapper enlarges the one-cut exponent from C to C+1. It takes H = 16(a₀+217). The hypotheses include U ≤ τ ≤ v^(Hα), sv⁴⁸ ≤ τ and (lg v)^(Ccut·α) ≤ v. They ensure the one-cut logarithm condition at every call and absorb the cumulative overhead. In the following calculations T and S are the current time and size bounds. [Statement and constants](../primary/vp-vnp/Paper/Cuts.lean#L460) · [Overhead and one-cut instantiation](../primary/vp-vnp/Paper/Cuts.lean#L487)

| Step | Independent calculation |
|---|---|
| Regular cut, TΛ ≥ Uv⁶⁴ | Set k = v⁶³ and T′ = ⌊TΛ/k⌋. Then Uv ≤ T′ ≤ T/v⁶² since Λ ≤ v. Equality at the switch gives T′ = Uv. Every regular cut makes progress while leaving the next cut above its minimum scale. |
| Terminal cut, TΛ < Uv⁶⁴ | Set k = ⌊TΛ/U⌋+1. With T ≥ U and Λ ≥ 2, we have 2 ≤ k ≤ v⁶⁴ and ⌊TΛ/k⌋ < U. The result can be advertised as U-plain. At T = U this executes one legal cut with k = Λ+1. |
| Size and count | If Sv⁴⁸ ≤ cT with c ≥ 1, the two terms of S′ = (⌊S/k⌋+⌊T/v²⁵⁶⌋)Λ give S′v⁴⁸k ≤ 2cTΛ using k ≤ v⁶⁴. Regular-cut rounding gives TΛ ≤ 2kT′, hence S′v⁴⁸ ≤ 4cT′. The count at a regular step satisfies (kΛ)T′ ≤ TΛ². The terminal bound kU ≤ TΛ+U pays for reporting time U. |
| Cost of composition | For successive cuts with piece bounds P₁,P₂ and accepting times t₁,t₂, the source charges t₁ + P₁(t₂ + 62P₂ + 110) + 100 and allows P₁P₂ pieces. Code size is bounded by the first program size plus three times the second plus 3000. The list construction has an explicit budget even when child times are small. |

The induction uses r = Hα as a bound on recursion depth, allowing up to r+1 cuts. Its three loss factors are (4Λ²)^(r+1) for count, (100Λ³)^(r+1) for time, and (8Λ)^(r+1) for size. The scale hypothesis bounds even the largest by v. Cross-multiplication then gives PU ≤ τv, tv⁴⁷ ≤ τ and final piece size ≤ v^(H−47). Each implies the advertised P ≤ ⌊τv²/U⌋, t ≤ ⌊τ/v²⁴⌋ and size ≤ v^(H−32), respectively. The wrapper also bounds the resulting program size by U. These margins apply under the same tower and scale hypotheses.
