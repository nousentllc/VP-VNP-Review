## What the two theorem statements have to preserve

**C.3.** For a field $K$, a set of labels $V$, and a price $w$ over $K$, there exists one metric space $X$, with its complete midpoint structure, and a map $f:V\to X$ such that (i) the *entire* distance function of $X$ is a price over $K$ and (ii) $d_X(f(a),f(b))=w(a,b)$ for all $a,b$. The map may identify labels at distance zero. The publisher’s `IsPrice` tests every finite list of labels against the closure of scaled spectral distance tables over that same field. Its `CN` structure includes completeness and, for each $x,v$, a single midpoint satisfying the squared inequality for every $z$. These quantifiers explain why proving only that each old pair has the prescribed distance would leave a gap for D.2’s later cube points. [Price predicate](../primary/vp-vnp/Nc/Price/Basic.lean#L74) · [Complete-space and midpoint definition](../primary/vp-vnp/Nc/Cat/Core.lean#L22) · [C.3](../primary/vp-vnp/Paper/Curvature.lean#L211)

The construction extends a price to formal midpoint terms, gives the terms their pseudometric, and maps them into the completion. The completion argument extends the midpoint inequality from a dense subset. A separate finite-restriction limit proves the ambient distance is a price. The full C.3 proof calls C.1 to obtain the inequality at the dense midpoint terms. [Formal midpoint family](../primary/vp-vnp/Paper/Curvature.lean#L58) · [Dense subset](../primary/vp-vnp/Paper/Curvature.lean#L166) · [Ambient price](../primary/vp-vnp/Paper/Curvature.lean#L194) · [C.1 call in C.3](../primary/vp-vnp/Paper/Curvature.lean#L230)

**D.2.** Flatness requires every finite Euclidean configuration to be a price over $K$. Contraction requires a matrix size $\mu\ge2$ and a scalar $s\ge1$ with $s^2<\mu$, chosen before every price on $\mathrm{Mat}_\mu(\mathbb F_2)$, such that $D(\mu)\le sD(1)$. The finite binary matrices index labels even when the field defining prices has another characteristic. If contraction fails, for each $\mu\ge3$ the proof first obtains one price with $w(a,b)^2=\mathrm{rank}(a-b)$ for every pair. It applies C.3 to *that* price, fills a Euclidean cube in the ambient space, and recovers the desired finite configuration by pullback and scaling. Choosing $\mu=k+3$ covers every finite dimension $k$. The theorem concludes an inclusive disjunction. Determining an effective or unique choice for a specified field would require additional information. [Branch predicates](../primary/vp-vnp/Paper/Alternative.lean#L53) · [Common rank price](../primary/vp-vnp/Paper/Alternative.lean#L706) · [Euclidean configuration and C.3 call](../primary/vp-vnp/Paper/Alternative.lean#L857) · [Final disjunction](../primary/vp-vnp/Paper/Alternative.lean#L921)

**The field quantifier at the caller.** The formal D.2 declaration takes `K : Type`. The final M.3 takes arbitrary `F : Type u`. M.3 chooses the algebraic closure of the prime field in `Type` for each characteristic, applies D.2 there, and uses the same-size M.1 descent to handle a circuit over $F$. This accounts for the universe difference at these interfaces. D.2 itself yields a geometric alternative. Ruling out every small circuit still requires a branch lower bound, the target-polynomial reduction, and transfer. ## Reproduction

The [replay runner](../checks/pass09_endpoint_replay.py) reads the pinned Lean version and publisher package manifest, checks each external checkout revision, and compiles the publisher project imports into a fresh empty object directory. The external Lean toolchain, mathlib and its dependencies are prebuilt. Set `MATHLIB_DIR` to that built checkout, put its pinned `lean` executable on the path, and run from the review root.

```sh
python3 checks/pass09_endpoint_replay.py --target-module Paper.Alternative \
  --query-file checks/pass12e_alternative.lean --mathlib "$MATHLIB_DIR" \
  --output /tmp/pass12e-alternative.json
python3 checks/pass12e_verify_pin.py
```

The second command validates the archived receipt against the files in the handoff. It recomputes the source-tree object ID from the file names, modes and bytes, verifies the source hashes for every requested module and the query file, and checks the recorded dependency revisions and axiom results. The first command writes a separate receipt for the new run. [Statement and axiom queries](../checks/pass12e_alternative.lean) · [Offline source and receipt check](../checks/pass12e_verify_pin.py)
