## The quantifiers that matter

K.2 accepts a topologically numbered arithmetic circuit for an arbitrary polynomial over a commutative ring R, with constants from R, unbounded fanout and ordered binary operation sockets. S bounds its gate count. Choose M and m so S ≤ 2^M and N ≤ 2^m. Here N counts word positions, each holding zero, one, or the end mark as a symbol in the encoded assignment. Given any degree cutoff d, the compiler provides one constant trie K and one program D. They work for every coefficient-source ring A with an A-algebra structure on R, every coefficient map θ and every tree z of size less than N. The answer is the sum of homogeneous components of degrees 0 through d evaluated on the code of z. This theorem assumes neither an a priori bound on intermediate degrees nor plainness of z. [K.2 declaration and cutoff-zero case](../primary/vp-vnp/Paper/LowDeg.lean#L42)

K.3 fixes A, a finitely supported θ, H ≥ 32 and a grid-completeness factor κ. There exist B₀>0, C, v₀. For every field F equipped with an A-algebra structure, every κ-grid-complete family G, every v≥v₀, every integer a≥0 satisfying (lg v)^(Ca)≤v, and every matrix order m≥v^B₀, any circuit witness for Gₘ with ≤vᵃ gates implies an accelerator at scale v of size ≤v^(C(a+1)). K, D and the projection may depend on the chosen scale and witness. They must be fixed across the short inputs on which their guarantee is asserted. Source values live in A and map to F through the algebra map. The permanent specialization assumes 2≠0 in F. The Hamiltonian-cycle grid realizes the general interface for all fields. ## K.2, gate recurrence

For every gate g, let c_g=p_g(0) and q_g(j)=[Tʲ]p_g(Tu). Scaling a monomial of degree j multiplies it by Tʲ, so the coefficient is its homogeneous component evaluated at u. At a product with ordered predecessors h,v the coefficient for j≥1 is c_v q_h(j)+c_h q_v(j)+Σ_{0<i<j}q_h(i)q_v(j−i). At a sum the coefficients add. No division, interpolation, positivity or bound on syntactic degree enters. [Line coefficient](../primary/vp-vnp/Paper/LowDeg.lean#L20)

Induct on the gate index. For each gate build a row λ indexed by variables and a row κ indexed by ordered pairs of gate addresses. With a_g=Σ_x λ_g(x)u_x one obtains

    q_g(j) = [j=1] a_g + Σ_{l,r} κ_g(l,r) Σ_{0<i<j}q_l(i)q_r(j−i).

Rows vanish at a scalar. At a variable one λ entry is one. Gate addition adds the rows. Gate multiplication g=hv gives λ_g=c_v λ_h+c_h λ_v and κ_g=c_v κ_h+c_h κ_v+δ_(h,v). Source induction initially charges the last term to the product gate, choosing a valid decomposition if the same polynomial admits several. It then groups by the chosen ordered address pair and pads unused addresses with zero weight. Socket symmetry affects values, while the input positions in the convolution still count separately. For the simple test g=(1+x)², uₓ=1, the degree-one coefficient is two. It cancels in characteristic two. Treating a repeated reference as a single edge fails over the integers. ## K.2, forest invariant and machine accounting

Define E_g(T)=Σ_{j≥1}q_g(j)T^(j−1). Then E_g=a_g+TΣκ_g(l,r)E_l E_r. For a list L of pending gates and integer budget b≥0 write W(b,L)=Σ_{j=0}^b [Tʲ]∏_{g∈L}E_g. An empty list has W=1. Expanding the first factor gives

    W(b,g::L) = a_g W(b,L) + [b>0] Σ κ_g(l,r) W(b−1,l::r::L).

For d≥1, the required answer is c_out+W(d−1,[out]). The counter decreases on a split, stays fixed at a leaf, and the integer 2b+length(L) falls by exactly one on either move. Its initial value 2d−1 bounds every branch's number of rounds. The pending stack has at most d gates. For d=0 the publisher dispatches to the constant polynomial c_out with an internal cutoff of one. The reasoning preserves arbitrary continuation stacks, including repeated names. A proof by counting distinct gate indices in the pending list would lose this property. [Preorder loop](../primary/vp-vnp/Nc/Acc/Loop.lean#L182) · [program value and cost](../primary/vp-vnp/Nc/Acc/Prog.lean#L239)

Input preparation converts the tree word plus end marker to a balanced access tree. Guessing a variable address accesses the input letter. The lookup returns the associated λ or zero for padding. A split guesses gate addresses and bills κ. The advice also holds c_out. A leaf of the advice trie at path l uses the suffix 1ⁱ0 for its 2ⁱth power. B=1 allows i=0, so even a plain leaf value has its zero terminator. The accelerator writes a name and continues independently of its scalar value. Its weighted acceptance is the sum over the list of accepting runs r of ι(r.th) times the product of K.lk(q) over every occurrence q in r.bill. The empty bill contributes the multiplicative unit. Duplicate branches count. Zero-weight accepting runs can appear, so identifying raw accepting multiplicities with nonzero symbolic terms is stronger than the verified value identity. ## K.3, reconstructing the polynomial supplied to the compiler

Let Aₜ(w) denote the fixed automaton's time-t weighted path sum on the word w. A marked word C(w) contains one true input cell in each consumed row and an end mark at row |w|. The printed polynomial is Σ_w Aₜ(w)X_{C(w)}, for |w|<N. Two distinct marked words cannot have comparable supports. At the end of a proper prefix the longer word uses an ordinary letter. Incomparable non-prefix words disagree already at their first mismatched symbol. Thus evaluating a marked-word monomial at a canonical code isolates its word. Omitting the end marker fails, for example for [0] and [0,1]. [Manuscript](../primary/vp-vnp/paper.pdf#page=57) · [canonical code](../primary/vp-vnp/Nc/RunMn.lean#L27)

The source builds an extension f↦Σ_x f(x)X_support(x) using the hidden assignment sum f(x), then expresses that extension as a clause sum. For a fixed starting and ending state, ordered transitions and valid single-channel input, the counters are forced by cumulative emissions. The side tape words and blanks are forced too. The state path remains a summed index, even if a matrix entry is zero. State-path multiplicity is therefore weighted once per path on matched inputs. Input-pattern constraints allow at most one symbol in a row, and require one unless an earlier end has appeared. A successful run on an arbitrary admissible pattern fixes its own input letters at rows 0 to |w|−1 and its own end at |w|. An independent expansion of the concrete single-channel construction is

    Φ_src = Σ_w Aₜ(w) X_C(w) ∏_{j>|w|,j<N} (1+Σ_{α∈Γ∪{#}}X_{j,α}).

To see this, fix the letters, state path, counters and tape certificate of a matched run. Modifying rows strictly past its end preserves every hidden condition. Each such row has the independent choices empty or a single allowed symbol. Conversely, starting the input counter at zero and advancing by each consumed letter forces one determinate prefix and end in any contributing certificate. Restrict that pattern to this canonical prefix and apply unique certificate reconstruction. Each allowed choice of trailing rows recreates the same hidden witnesses. This is a derivation from the single-input source construction. The pinned theorem directly proves the weaker interface actually needed, namely degree ≤N and equality to Aₜ at every canonical code of length <N. It also supplies nonempty clauses, coverage of all variables by literals, variable-or-constant weights, and an explicit literal bound. ### Finite counterexample to a global polynomial identification

Take N=3, t=1, a binary alphabet, one state that starts and ends, and no auxiliary tapes. Only the transition consuming zero has weight one, all other transitions have weight zero. With A=X_(0,0)X_(1,#) and B=1+X_(2,0)+X_(2,1)+X_(2,#), the printed construction gives A while the source construction gives Q=AB. They agree on every marked word. Adding another end at row two gives integer values one and two, respectively. This demonstrates a genuine difference between the constructed polynomials. The theorem requires equality only on marked words, and the formal construction meets the same degree cap. The counterexample does not invalidate K.3. It also shows why treating the pinned extension as the ordinary multilinear interpolation of all truth-table values would misread its definition.

### An independent way to recover the printed polynomial exactly

For every p<q<N and symbol α (end included), add a zero-weight clause that fires precisely when rows p and q carry the end mark and α, respectively. The source's clause-product convention assigns the specified weight when every listed literal matches and one otherwise. These guards eliminate every nonempty choice in the trailer. The hidden end condition already excludes the end-free patterns. Thus the stronger clause family represents the printed word sum as a polynomial, while retaining every canonical evaluation. It adds exactly (|Γ|+1)N(N−1) literal occurrences with no extra variables. Writing B=t+N+|Q|+|Sₜ|+|Γ|+2, the old literal bound 1600 B⁹ becomes at most 1601 B⁹ for this independent variant. Its projection needs only the corresponding constant threshold. The publisher uses the unguarded 1600-bound construction for K.3. The executable compares each of the 2,048 guarded coefficients with the independent exact-word sums. This stronger variant is an independent derivation. [Zero-weight literal convention](../primary/vp-vnp/Nc/RunMn.lean#L139)

### A complete finite path through the K.2 mechanism

1. Gate 0 loads X_(0,0), gate 1 loads X_(1,#), gate 2 forms A. Gates 3–6 load 1 and the three row-two variables. Gates 7–9 sum these for B. Gate 10 forms Q. Gate 11 is gate 10 plus itself. Gate 12 stores −1. Gate 13 multiplies gates 12 and 10. Gate 14 sums gates 11 and 13. Shared references yield 2Q−Q.
2. On the code [0], which represents the empty tree, A(Tu)=T² and B(Tu)=1. Gate 10 inherits κ_(g0,g1)=1 from A because c_B=1. Its additional split (A,B) has zero positive contribution at this evaluation. Gate 11 doubles the table. Gate 13 subtracts it, with an additional split into the constant −1 and gate 10. The positive part of the constant branch vanishes. The surviving pair (g0,g1) uses one split and two matching leaves. Other paths can have zero weight. At cutoff two, the net accepting weight is one.
3. The outputs for d=0..4 are [0,0,1,1,1]. In characteristic two the intermediate doubled value is zero and the negative copy becomes positive. On the malformed double-end pattern the line polynomial changes to T²+T³. A program accepting the word as a set of states or using only nonnegative coefficients could not justify these cancellations.
4. This explicit automaton exercises a single-channel clause construction and a circuit computing that construction. It does not instantiate the universal I.1 machine, a whole grid-complete family, or diagonalization at a large scale. Those are quantified separately below.

## The universal construction, scales and contradiction

1. For fixed θ choose I.1's weighted automaton, independent of F, v, m and the hypothetical circuit. Define N=v^(H−32)+1 and t=v^(H+1). The simulation needs Cᵤ(|z|+vᴴ)lg²(|z|+vᴴ) ≤ 2Cᵤ(H+1)²vᴴ(lg v)² ≤ t above its threshold. At that time the plain instance z has exactly the required weighted value. Distinctness of the two binary symbols follows because identifying them would make the input words identical for two equal-size plain inputs with values one and zero. The source uses quote-nil and fail, exchanging program and argument to preserve total tree size. An A-algebra field F ensures A is nontrivial. Set unused alphabet variables to zero, retaining the end variable. 2. With Q states, Sₜ side tapes and alphabet Γ, literal count ≤1600(t+N+|Q|+|Sₜ|+|Γ|+2)^9. Eventually the parenthesis is ≤v^(H+2) and 1600κ≤v. Then κ times the literal count fits into any m≥v^(9(H+2)+1). Affine here means a constant or one scaled and translated variable. Three possibly charged constants/variable leaves and two arithmetic gates per replaced variable gate explain the general ≤5s bound with arbitrary shared gates. ## Evidence and reusable mechanisms

The declaration chain supports the broad circuit model including reuse, cancellation, arbitrary named field constants through nonuniform advice, and polynomially many advice nodes by the theorem's size metric. The off-code equality is refuted for the concrete witness and is unnecessary. Independent payoffs are the context-indexed forest invariant (preservation under arbitrary pending continuations), the integer potential 2b+length(L) (bounded computation with possible nondeterministic branching), and canonical-code agreement under a globally degree-bounded extension (the relevant representation property for this consumer). Application to a different field, resource model or continuation requires its own hypotheses. This track draws no evidence from RCMG. Global kernel and Comparator outcomes are reported separately in Edition 11's formal receipts.
