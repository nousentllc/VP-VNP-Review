# Post-primary one-call reserve deliverability stress and recovery experiment

The published W06-E primary experiment has finished. An independent inventory-only perturbation found 137 up-call and 133 down-call conflicts on the primary continuation controller. Keep those findings and the earlier cost results. Use all 16 previously analyzed paths, with no changes to the source panel or issued information. This is a post hoc repeated-panel robustness test and has no new confirmatory p-values. Freeze this supplement and its implementation before running it.

At each hour, test the base signed internal storage command q, the entire mandatory upward call q−u, and the entire downward call q+d. These are separate one-hour branches from the actual beginning SOC and preceding applied signed command. Require each to respect currently available power, accessible energy after discharge, signed setpoint ramp of two blocks, inventory operating range [2,11] MWh and grid import [0,9] MW with all booked/critical service identical. One reserve block is one stored MWh per hour; the AC-side response is 0.9 to 1.1 MW per block as the command crosses sign. This model makes no equal-AC-MW procurement claim. A supplementary one-block upward bid earns the original fee only if combined mandatory-plus-optional upward call q−u−1 is valid. Zero available power suspends bids and mandatory commitments as in the original contract.

Require every call endpoint (including optional bids) to admit a causal no-further-call recovery to final SOC 9, with known hour, published end-of-horizon clear window and arbitrary subsequent per-hour power envelope {0,1,2} elsewhere. After the first hypothetical call, preserve ordinary posted power reservations and service during recovery, with no more calls assumed; upcoming uncertain power is observed before action. On the nominal path, retain robust future viability for this one-call contract. Use a backward exact Boolean viability kernel; record and check kernels. Actual paths used to price the standing service have zero calls. An adversarial one-hour branch is tested from each eligible hour separately. Only the feasibility of one call and its recovery is assessed. Costs of activation and multiple calls or reserve reliability in deployment are unresolved. Instant reset to the pre-call trajectory is not assumed.

Freeze all monetary parameters and controller marks from previous development. Evaluate common current observation/H12 issues, price-aware single-step rule with $70 mark, deterministic H12 with $65 end mark, and equally weighted three-scenario H12 with same $65 mark. Clock includes construction, feasibility test and action selection. Fallback to the feasible price rule at one second. First calculate the matched complete-information optimal no-call cost under the same one-call viability rules and target all 16 paths. If a path's initial state has no feasible policy or a mandatory hour admits no action, save that fact. Keep infeasible paths in all denominator statements. Otherwise evaluate the online policies. Report nominal costs, reserve payments, all calls audited, contingency and fallback counts, timing, risk and net-value limits. Record all synthetic inputs by immutable references to the parent E/inputs and checksum. Compare with original figures only within the same contracted model.
