# Independent static AC and unit commitment checks

Run from C/independent_review using the same Pyomo version as the campaign. The rank-one checks require only the Python standard library. The source defaults to the enclosing C folder. Choose a new output directory for your replay.

    PYTHONDONTWRITEBYTECODE=1 PYTHONHASHSEED=902 python review.py --source .. --out /tmp/w06-c-independent
    PYTHONDONTWRITEBYTECODE=1 python ac_lifts.py --source .. --out /tmp/w06-c-independent

The first checker reparses the public MATPOWER files, reconstructs tapped series and charging current independently of the AC solver/admittance builder, tests both branch ends and angle constraints, and evaluates the lossless copperplate dual price in exact rational arithmetic. It reads both interior midpoint witnesses, checks their floating bus residuals and compares fuel to the rigorous upper enclosure. Midpoint residuals alone establish no AC existence result. That result rests on the separate Arb interval contraction in the C campaign. For a fixed point of x−RF(x) on the selected-coordinate box, the contraction inequality is sufficient because the strict Jacobian norm test also makes RJ and hence square R nonsingular. The other coordinates are fixed to the exact proposed values. The enclosure checks operate on a superset of the certified box.

The second checker evaluates the stored canonical imaginary signs in both-end flows, every pairwise product cut at an arbitrary exact rational rank-one voltage vector, and each stored exploratory clique PSD cut against its independently computed squared complex inner product. Changing the imaginary sign fails the check. This tests orientation and selected-row algebra. General validity of each clique and edge cut follows from the corresponding squared norm being nonnegative for any voltage vector. It does not independently regenerate each AC LP dual.

For UC the first checker instantiates the shipped upstream Pyomo formulation on exact JSON decimals, confirms every serialized row and column label against canonical ordering, assigns exact rationals to the original Pyomo variables and directly evaluates every original constraint and objective. It checks every lower-bound vector with a separate linear expression-tree implementation, projections onto physically implied variable boxes and exact arithmetic. This implementation does not import commitment.py, linear.py, the original coefficient extraction routine or HiGHS. A chronological direct check of the 11 actual starts found all selected categories consistent with elapsed offline time, including pre-horizon history. A zero-start case has an empty startup count. The UC model has a global balance and joint reserve requirement without network or contingency constraints.

The review uses the same benchmark sources and received artifacts, with an independently written implementation in the same working group. It is a computational cross-check, not independent field replication. The stored receipt.json and ac_lifts.json are the exact run outputs.
