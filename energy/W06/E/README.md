## Reproduce

Python 3.12.9 with NumPy 2.2.4 and SciPy 1.18.0 was used on macOS arm64. The independent fresh-state Bellman checker uses NumPy and integer arithmetic. SciPy/HiGHS is used for historical price LPs and the supplementary network-flow LP demonstration. From E in a fresh environment, run the following with an empty destination outside the release.

```sh
python -m pip install -r requirements.txt
PYTHONDONTWRITEBYTECODE=1 python reproduce.py audit --out /tmp/crgc-w06-e-audit
PYTHONDONTWRITEBYTECODE=1 python reproduce.py run --out /tmp/crgc-w06-e-rerun
```

The full run expects the original W05 experiment archive and independent review ZIP in W06/dependencies. Amendment flags `--w05 /path/to/W05_Energy_Experiments.zip --review /path/to/CRGC_W05_Independent_Opportunity_Review.zip` select an alternative location. SHA-256 identities are enforced. The output includes phase elapsed times. Costs and rational witnesses are deterministic under the recorded settings. Per-hour/QC/serialization elapsed times and time-dependent fallbacks can vary on another host.

## Run order and data layout

1. `historical/replay.py` validates all W05 archive members through the original independent reviewer, reconstructs the exact causal fill from scratch, checks each action against the archived certificate and compares to the stored online actions. `historical/results.json` records both regressions.
2. `protocol/design.md` and `protocol/freeze.sha256` fix the primary experiment's generators, policies, pricing, test and gate. `gate.py` writes actual inputs/issued forecasts, selects a baseline on development trajectories, runs exact retrospective Bellman recursions before candidate evaluation and publishes `results/gate.json`. Credit selection checks this artifact first. The two development paths and 16 holdout paths under inputs/ are synthetic. The embedded tuple column names define units and ordering. The two elements per arrivals row are counts of mandatory high and lower-priority bookings with offsets 2 and 5 hours.
3. `compare.py` writes the development-selected mark and the applied policies, including rejected-proposal counts and timing. `baseline_*.json.gz` contains price-rule and loose-final-stock fill trajectories and daily-reset controls. `online_*.json.gz` contains fixed-stock fill, H6, H12 and H12 with continuation. Each action has fields [signed internal MWh, end SOC MWh, optional one-hour offer, stage objective cents, decision ns, fallback reason]. The final credit is separate. Applied decisions and incoming observations reconstruct all imports, throughput, jobs and reserve margins. `match_terminal` enforces 9 MWh on the actual path. Opportunities before a proposed controller exists are relative to price-rule cost.
4. `cert_*.json.gz` stores row-level, full-state integer Bellman potentials for all eight contract variants. States enumerate SOC 2 through 11 outside, prior signed action −2 through 2 inside. The final state potential encodes inventory credit. A value of 1,000,000,000,000 cents marks an unreachable state; no finite path cost approaches this sentinel. The independent scalar transition implementation in `audit.py` verifies every feasible edge, recovers attaining paths, verifies issued information/queues, independently checks every applied primary control, and tabulates split cost/service metrics in `results/audit.json`. `results/summary.json` contains paired intervals, sign tests, Holm adjustments and clocks. `controls.py` rejects mutated SOC, non-issued forecasts and a one-cent false lower bound.
5. `protocol/supplement.md` is a separate post-primary plan for the untuned contract mark, three-scenario rolling benchmark and 24 network-flow LPs. The net flow LP has one unit of flow from the current state through successive state/action layers. Its node-arc incidence matrix is totally unimodular. These H12 zero-continuation LP checks cover 24 declared hours in the first path. The rolling DP on all paths solves the same shortest-path model. `results/supplement_summary.json` retains all stochastic and untuned comparisons, system checks and timing.
6. `protocol/historical_splice.md` and `protocol/analytic_extension.md` document two exploratory original-scale tests after primary analysis. `historical/splice.json.gz` stores chronological order, exact feasible upper stocks and costs, LP multipliers and exact economic gaps. `historical/check_splice.py` verifies all 24 boxed weak-dual bounds from the stored multipliers without an optimizer. `historical/analytic_stock.py` verifies a separate closed-form discharge bound in exact arithmetic on all 252 single-day inputs and all 12 splices. The stored results report the exact stock and throughput terms for every case.

## Scope and provenance

The W06 site, prices, issue process, outage distribution, workload classes, reserve fees and degradation coefficients are authored synthetic research inputs. All jobs are served at booked slots in the fixed-profile arms. No real jobs, field prices, cell measurements or deployment spending are present. The model assumes no reserve activation and a publicly available end-of-horizon recovery period. Mandatory reserves scale down during outages. The strong-policy roster is documented in the freeze. The more demanding three-scenario benchmark is supplementary. The complete delivered designs and evidence distinguish the two.

Prior research establishes energy-storage stochastic value functions and cycle-aware wear modeling. These sources motivate model comparison; neither validates the chosen site parameters. [Zheng, Jaworski and Xu](https://doi.org/10.1109/TPWRS.2022.3154353) · [Xu, Zhao, Zheng, Litvinov and Kirschen](https://arxiv.org/abs/1707.04567).

A clean full second run is recorded in [replay verification](results/replay_verification.json). To compare a fresh full run, execute `python check_replay.py /tmp/crgc-w06-e-rerun ../dependencies/CRGC_W05_Independent_Opportunity_Review.zip /tmp/crgc-w06-e-comparison.json`. The comparison checks all controls and fallbacks, all Bellman potentials, original-scale paired results and original input bytes. It also compares the independent analytic bound with Chat's case-by-case LP economic ceilings.
