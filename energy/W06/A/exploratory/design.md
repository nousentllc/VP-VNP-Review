# Post-primary baseline-strength sensitivity

The primary W06-A results found residual opportunity concentrated in negative-price/outage and time-of-use families. They also showed that direct state enumeration often costs less than LP certification. On the same 72 designed paths, use a stricter comparator to test how much certified opportunity persists when cheap additional planning is already deployed. This is an exploratory re-use of the panel after results, with no new confirmatory status.

Use the filed primary four-hour baseline and its exact schedules. Run two sweeps with window length eight and offsets zero/four, initialized by that baseline and accepted only if they preserve or improve the primary objective. Service assesses total shed with the original terminal contract. Cost holds each hour's original baseline service exactly fixed. Keep original absolute-and-relative thresholds numerically fixed using the original baseline, and subtract the stronger baseline's feasible objective from the **same** independent whole-horizon global optimum; this isolates baseline dependence without moving goalposts. Record exact before/after gap, valid witness, and incremental model/check wall-clock. Compare caps by regime; report regressions and missing paths. This duration is a sensitivity choice, not a held-out hyperparameter.
