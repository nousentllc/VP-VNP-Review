# Independent W05 review — opportunity bounds

Run `python opportunity_review.py /path/to/W05_Energy_Experiments.zip results.json` in Python with NumPy and SciPy. The script independently reconstructs the daily plant matrices, checks each of the original 252 exact service witnesses and bounds, then generates two new post hoc economic LP lower-bound certificates per scenario-day. It does not execute the archive's code or alter original files.

The original fill schedule is an exact feasible upper witness. Economic cost uses illustrative flat $50/MWh imports, $10/MWh charge-plus-discharge throughput and $50/MWh final stored energy credit. Both comparisons fix every hour's flexible load shed to the exact fill schedule. One fixes the same end inventory; the other retains the original terminal floor and credits inventory. Simultaneous charge/discharge is relaxed for the lower bound; numerical candidate outputs are checked for exclusivity and all model constraints. Exact rational evaluation of dual multipliers provides a valid lower bound for the encoded binary64 coefficient model. Numerical candidates are not claimed exactly feasible or deployable online. This is retrospective, synthetic, sample-specific, and excludes all real-world prices, forecast limitations, degradation, integration and physical actuation. Neither result is a commercial saving. Separate from the W05 primary protocol.

The JSON records per-case rational cost-gap values, case-model numerical residuals and aggregate results. The exact service-bound reconstruction agrees with the original archive.
