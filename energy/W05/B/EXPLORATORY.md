# Two diagnostics of anchor choice

**Question.** A cheap fixed anchor may avoid an LP but give a poor repaired schedule. What fails when the anchor lies on a boundary, and can two existing anchors repair more gently? The following are mathematical stress cases. No held-out dispatch was selected for these examples.

**An arbitrarily small violation can cost one unit.** Let the first coordinate be constrained by u≤0 and the second v∈[0,1]. Give (ε,0), ε>0, to the reconstruction and use anchor (0,1) with objective J(u,v)=v. At the violated row the anchor slack is zero, so the fraction is 1 for all ε. The repaired point costs 1 while (0,0) is feasible at cost 0 and is ε units away in Euclidean distance. A residual tending to zero gives no vanishing loss for this chosen anchor map. This is compatible with a Hoffman distance bound, which only promises that some feasible point is close. See formal/Obstructions.lean, theorem arbitrarily_small_violation.

**Complementary boundary anchors.** Consider u≤0, v≤0, raw point (1,1) and two anchors (−1,0), (0,−1) in the same fixed slice. Each anchor alone has zero slack in one violated row and therefore needs its full weight. Their average (−1/2,−1/2) gives λ=2/3, reaches (0,0), and costs zero for J=−u−v. Each single-anchor return costs 1. This example distinguishes a pool of independent ray choices from an anchor formed by mixing witnesses. See formal/Obstructions.lean, theorem mixture_of_anchors.

For multiple verified anchors aₖ within the same convex/equality/mode slice, x′=(1−Σwₖ)x̃+Σwₖaₖ, with wₖ≥0, Σwₖ≤1, is a candidate family. The remaining inequalities are affine in w. For affine objectives, minimizing the resulting cost is itself a small LP and retaining each single-anchor candidate supplies immediate upper bounds when available. The computational value of this intervention has not been tested. Anchor acquisition and changes to solve time, checking cost, quality and the full-mode comparator would need a separate prospective experiment.
