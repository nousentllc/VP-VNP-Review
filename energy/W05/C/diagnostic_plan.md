# Separate factorization instrumentation and extended-budget diagnostic

The standard IPOPT 3.14.11 / MUMPS 5.4.1 report prints the numerical factorization field as zero even when the backend performs elimination. A 57-bus development probe confirmed that MUMPS verbosity level three exposes the elapsed factorization time, actual node-elimination operation estimate reported by MUMPS (RINFOG(3)) and actual stored factor entries (INFOG(29)) per completed factorization. Collect these backend fields on all five arms of all five held-out cases at one repetition each, separately from the registered clock. The 1,888-bus case produced late, invalid outputs on the first primary round, motivating a uniform extended 60-second gate under this instrumentation. This secondary look is post hoc. Different logging and a different budget change the experiment. Do not pool these outcomes or use them to revise the original 12-second claim. The solver's internal wall allowance is set during model construction; independent total elapsed and checks govern all reported hits. Each raw .native.gz is the original console output and each .ipopt is the corresponding IPOPT log. All arms run in one serial lane after the primary runs.
